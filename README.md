# СубТрекер 💳 / SubTracker

Безкоштовний трекер підписок, який працює повністю у вашому браузері.
Free subscription tracker that runs entirely in your browser.

**Live:** https://valera99686.github.io/subtracker/
(дзеркало: https://host-html.com/p/n497wl — діє до 30.06.2026)

## Чому це існує

- 64.8% людей забувають скасувати тріал до першого списання
- Домогосподарства недооцінюють витрати на підписки майже втричі (~$273/міс проти уявних ~$111)
- Наявні трекери підписок самі вимагають підписку і доступ до банку

## Можливості

- Витрати на місяць / рік / день, мультивалютність (₴/$/€) з власними курсами
- Попередження про закінчення тріалів (банер за 7 днів)
- Детектор марних витрат: «можна заощадити N ₴/рік»
- Найближчі списання з відліком днів; дати автоматично переносяться на наступний цикл
- Графік за категоріями, пошук/фільтр/сортування
- Експорт/імпорт JSON, темна і світла теми
- Без реєстрації, без сервера, без телеметрії — один HTML-файл, дані в localStorage

## Запуск

Просто відкрийте `index.html` у браузері. Все.

## Постійний безкоштовний хостинг (GitHub Pages, ~2 хв)

1. Створіть репозиторій на github.com (наприклад `subtracker`), завантажте `index.html` через кнопку **Add file → Upload files**
2. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**
3. Через хвилину сайт буде на `https://<ваш-нік>.github.io/subtracker/`

## Файли

- `index.html` — увесь застосунок (~34 КБ, без залежностей)
- `promo/` — готові тексти для безкоштовного просування (Reddit, X, dev.to, DOU, Telegram, Hacker News, Product Hunt)
- `deploy-info.json` — службова інформація про публікацію (містить edit_token — не публікуйте його)
